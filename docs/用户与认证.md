# 用户与认证

## 模块

负责注册、登录、保持登录、退出，以及登录后的资料、密码、登录设备和第三方身份。

未登录访问需要登录的页面时进入登录页。登录页可以去注册页，注册页可以回登录页。填了手机号或邮箱时，注册前要先发送并校验验证码；校验通过后 10 分钟内可以注册，注册成功后该校验失效。登录或注册成功后进入账号页。

打开应用时如果还没有访问令牌，先用刷新接口换令牌：成功进入账号页，失败留在登录页。账号页内修改资料、修改密码、查看设备、绑定或解绑第三方身份，完成后仍留在账号页。退出当前登录、退出全部设备、撤销当前这台设备、账号停用，都回到登录页。撤销其他设备时留在账号页。

## 接口

成功时 HTTP 200。响应体是 `code`（string，固定 `OK`）、`message`（string，固定 `success`）、`data`（对象，字段见各接口）。失败时 `data` 为 null，状态见下一节。有 JSON 请求体的接口使用 `Content-Type: application/json`，多出来的字段会失败。

下面标了请求头的接口都要带 `Authorization: Bearer <access_token>`。访问令牌只来自注册、登录、刷新的响应，放在内存里。

`user` 在注册、登录、当前用户、修改资料里结构相同：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| id | number | 是 | 用户 ID |
| username | string 或 null | 是 | 用户名 |
| nickname | string | 是 | 昵称。新注册默认「新用户」 |
| avatar_url | string 或 null | 是 | 头像地址 |
| phone | string 或 null | 是 | 脱敏后的手机号。未绑定为 null |
| email | string 或 null | 是 | 脱敏后的邮箱。未绑定为 null |
| status | number | 是 | 账号状态。1 为可用 |
| roles | string 数组 | 是 | 角色 |
| created_at | string | 是 | 创建时间，UTC，RFC3339 |

### 发送验证码

`POST /api/v1/auth/send-code`

请求体：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| channel | string | 是 | `phone` 或 `email` |
| target | string | 是 | 手机号或邮箱。手机号为 11 位且以 1 开头 |
| code | string | 否 | 本接口不使用 |

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| expires_in | number | 是 | 验证码有效秒数，当前为 300 |

### 校验验证码

`POST /api/v1/auth/verify-code`

请求体：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| channel | string | 是 | `phone` 或 `email` |
| target | string | 是 | 与发送时相同的手机号或邮箱 |
| code | string | 是 | 6 位验证码。开发环境的邮箱可以填 `000000` |

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| valid | boolean | 是 | 校验通过时为 true |

### 注册

`POST /api/v1/auth/register`

请求体：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| username | string | 是 | 1 到 50 个字，不能含空格或 `@` |
| password | string | 是 | 至少 8 个字符，最长 72 字节 |
| phone | string | 否 | 不填表示不绑定。填写时必须先完成手机号验证码校验 |
| email | string | 否 | 不填表示不绑定。填写时必须先完成邮箱验证码校验 |

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| access_token | string | 是 | 访问令牌 |
| expires_in | number | 是 | 访问令牌剩余秒数，约 1800 |
| user | object | 是 | 当前用户 |

响应头 `Set-Cookie`：`refresh_token`，HttpOnly，Path 为 `/`，SameSite 为 Lax。浏览器保存，脚本读不到。之后的登录相关请求要带上 Cookie。

### 登录

`POST /api/v1/auth/login`

请求体：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| account | string | 是 | 用户名、手机号或邮箱 |
| password | string | 是 | 密码 |
| device_id | string | 否 | 设备标识，最长 100 字节 |
| device_type | string | 否 | 设备类型，最长 30 字节，例如 `web` |
| device_name | string | 否 | 设备名称，最长 100 字节 |

响应 `data` 与注册相同：`access_token`、`expires_in`、`user`。响应头同样写入 `refresh_token` Cookie。

### 刷新访问令牌

`POST /api/v1/auth/refresh`

无请求体。Cookie：`refresh_token`，取浏览器保存的值。

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| access_token | string | 是 | 新的访问令牌 |
| expires_in | number | 是 | 新访问令牌剩余秒数 |

响应头写入新的 `refresh_token` Cookie。旧 Cookie 立即失效。

### 退出当前登录

`POST /api/v1/auth/logout`

无请求体。Cookie：`refresh_token`。没有这张 Cookie 也按成功处理。

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| logged_out | boolean | 是 | true |

响应头清除 `refresh_token`。

### 退出全部设备

`POST /api/v1/auth/logout-all`

请求头：`Authorization`。无请求体。

响应 `data` 与退出当前登录相同：`logged_out`。响应头清除当前浏览器的 `refresh_token`。

### 当前用户

`GET /api/v1/users/me`

请求头：`Authorization`。无请求体。

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| user | object | 是 | 当前用户 |

### 修改资料

`PUT /api/v1/users/me/profile`

请求头：`Authorization`。只提交要修改的字段，未出现的字段保持不变。

请求体：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| nickname | string | 否 | 1 到 50 个字 |
| avatar_url | string 或 null | 否 | `http://` 或 `https://` 开头，最长 500 字节。null 表示清空 |
| gender | number | 否 | 0、1、2、3 之一 |
| birthday | string 或 null | 否 | `YYYY-MM-DD`。null 表示清空 |
| bio | string 或 null | 否 | 最长 500 个字。null 表示清空 |
| location | string 或 null | 否 | 最长 100 个字。null 表示清空 |

响应 `data` 与当前用户相同：`user`。

### 修改密码

`PUT /api/v1/users/me/password`

请求头：`Authorization`。

请求体：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| old_password | string | 是 | 当前密码 |
| new_password | string | 是 | 至少 8 个字符，最长 72 字节，且不能与旧密码相同 |

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| updated | boolean | 是 | true |

当前这台设备保持登录。其他设备的登录会被撤销。

### 登录设备列表

`GET /api/v1/users/me/sessions`

请求头：`Authorization`。无请求体。只返回未撤销且未过期的设备。

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| items | array | 是 | 设备列表，没有设备时为空数组 |

`items` 每项：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| id | number | 是 | 会话 ID |
| device_id | string 或 null | 是 | 设备标识 |
| device_type | string 或 null | 是 | 设备类型 |
| device_name | string 或 null | 是 | 设备名称 |
| ip_address | string 或 null | 是 | 登录 IP |
| user_agent | string 或 null | 是 | 浏览器标识 |
| created_at | string | 是 | 创建时间，UTC，RFC3339 |
| last_active_at | string | 是 | 最近活跃时间，UTC，RFC3339 |
| expires_at | string | 是 | 过期时间，UTC，RFC3339 |
| current | boolean | 是 | 是不是当前这台设备 |

### 撤销一台设备

`DELETE /api/v1/users/me/sessions/{session_id}`

请求头：`Authorization`。路径参数 `session_id` 为会话 ID。无请求体。

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| revoked | boolean | 是 | true |

撤销的是当前设备时，响应头清除 `refresh_token`。

### 绑定第三方身份

`POST /api/v1/users/me/identities`

请求头：`Authorization`。

请求体：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| provider | string | 是 | `wechat`、`google` 或 `apple` |
| authorization_code | string | 是 | 第三方授权码 |

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| id | number | 是 | 身份 ID |
| provider | string | 是 | 第三方名称 |
| created_at | string | 是 | 绑定时间，UTC，RFC3339 |

### 解绑第三方身份

`DELETE /api/v1/users/me/identities/{identity_id}`

请求头：`Authorization`。路径参数 `identity_id` 为身份 ID。无请求体。

响应 `data`：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| deleted | boolean | 是 | true |

## 要单独处理的状态

失败响应都是 `code`、`message`、`data: null`。下面按 `message` 分支。

这些状态出现在所有需要登录的接口：退出全部设备、当前用户、修改资料、修改密码、设备列表、撤销设备、绑定身份、解绑身份。

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| 访问令牌缺失、过期、无效 | 401 | UNAUTHENTICATED | 未登录 |
| 账号已停用 | 403 | FORBIDDEN | 账号不可用 |
| 账号没有对应权限 | 403 | FORBIDDEN | 没有权限 |
| 服务暂时失败 | 503 | UNAVAILABLE | 服务暂不可用 |

未登录时清掉内存中的访问令牌，转到登录页。账号停用同样回到登录页，不要再调刷新。没有权限和服务暂时失败留在当前页，展示 `message`。

刷新接口：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| Cookie 缺失、已用过、已退出或已过期 | 401 | UNAUTHENTICATED | 未登录 |
| 账号已停用 | 403 | FORBIDDEN | 账号不可用 |

刷新返回未登录时进入登录页。

登录：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| 账号或密码为空 | 400 | INVALID_ARGUMENT | 账号或密码不能为空 |
| 邮箱格式不对 | 400 | INVALID_ARGUMENT | 邮箱不合法 |
| 用户名过长 | 400 | INVALID_ARGUMENT | 账号不合法 |
| 账号不存在或密码错误 | 401 | UNAUTHENTICATED | 账号或密码错误 |
| 账号已停用 | 403 | FORBIDDEN | 账号不可用 |
| 尝试次数过多 | 429 | RATE_LIMITED | 请求过于频繁 |

账号或密码错误停在登录页，不区分账号是否存在。账号停用单独提示，不进入账号页。

注册：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| 用户名不合法 | 400 | INVALID_ARGUMENT | 用户名不合法 |
| 密码长度不合法 | 400 | INVALID_ARGUMENT | 密码至少 8 个字符，最长 72 字节 |
| 手机号不合法 | 400 | INVALID_ARGUMENT | 手机号不合法 |
| 邮箱不合法 | 400 | INVALID_ARGUMENT | 邮箱不合法 |
| 填了手机号但还没校验 | 400 | INVALID_ARGUMENT | 请先完成手机号验证码校验 |
| 填了邮箱但还没校验 | 400 | INVALID_ARGUMENT | 请先完成邮箱验证码校验 |
| 用户名已被占用 | 409 | CONFLICT | 用户名已存在 |
| 手机号已被占用 | 409 | CONFLICT | 手机号已存在 |
| 邮箱已被占用 | 409 | CONFLICT | 邮箱已存在 |
| 尝试次数过多 | 429 | RATE_LIMITED | 请求过于频繁 |

发送验证码、校验验证码：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| 通道不是 phone 或 email | 400 | INVALID_ARGUMENT | 验证码通道不合法 |
| 手机号不合法 | 400 | INVALID_ARGUMENT | 手机号不合法 |
| 邮箱不合法 | 400 | INVALID_ARGUMENT | 邮箱不合法 |
| 验证码为空、过期或不匹配 | 400 | INVALID_ARGUMENT | 验证码错误 |
| 尝试次数过多 | 429 | RATE_LIMITED | 请求过于频繁 |

修改资料：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| 提交了用户名、手机、邮箱、密码、状态、角色等字段 | 400 | INVALID_ARGUMENT | 不能修改该字段 |
| 有不能识别的字段 | 400 | INVALID_ARGUMENT | 包含不能识别的字段 |
| 昵称不合法 | 400 | INVALID_ARGUMENT | 昵称不合法 |
| 头像地址不合法 | 400 | INVALID_ARGUMENT | 头像地址不合法 |
| 性别不在 0 到 3 | 400 | INVALID_ARGUMENT | 性别不合法 |
| 生日格式不对 | 400 | INVALID_ARGUMENT | 生日不合法 |
| 简介过长 | 400 | INVALID_ARGUMENT | 个人简介不合法 |
| 所在地过长 | 400 | INVALID_ARGUMENT | 所在地不合法 |

修改密码：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| 新密码不合法或与旧密码相同 | 400 | INVALID_ARGUMENT | 新密码至少 8 个字符，最长 72 字节，且不能与旧密码相同 |
| 旧密码不正确 | 401 | UNAUTHENTICATED | 旧密码错误 |

旧密码错误留在修改密码页，不清登录态。

撤销设备：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| 路径里的会话 ID 不是正整数 | 400 | INVALID_ARGUMENT | 会话不存在 |
| 会话不属于当前用户，或已经撤销、过期 | 404 | NOT_FOUND | 会话不存在 |

绑定第三方身份：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| provider 不是 wechat、google、apple | 400 | INVALID_ARGUMENT | 不支持的第三方 |
| 没传授权码 | 400 | INVALID_ARGUMENT | 缺少授权码 |
| 请求里带了 provider_user_id | 400 | INVALID_ARGUMENT | 不能直接提交第三方用户标识 |
| 授权码换票失败 | 401 | UNAUTHENTICATED | 第三方身份校验失败 |
| 该身份已经绑定过 | 409 | CONFLICT | 该第三方身份已绑定 |
| 服务端还没配置第三方换票 | 503 | UNAVAILABLE | 第三方登录尚未配置 |

解绑第三方身份：

| 触发条件 | HTTP | code | message |
|---|---|---|---|
| 路径里的身份 ID 不是正整数 | 400 | INVALID_ARGUMENT | 身份不存在 |
| 身份不存在或不属于当前用户 | 404 | NOT_FOUND | 身份不存在 |
| 解绑后没有任何登录方式 | 409 | CONFLICT | 至少保留一种登录方式 |

任意带 JSON 请求体的接口，JSON 无法解析或包含未定义字段时：HTTP 400，`code` 为 `INVALID_ARGUMENT`，`message` 为「请求参数不合法」。

## 明确不要做的事

- 不把 `access_token` 写入 `refresh_token` Cookie，也不把刷新令牌放进请求体、localStorage 或页面脚本能读到的位置。
- 不在注册请求里提交验证码、设备信息或其他未列出的字段。
- 不根据访问令牌是否过期判断刷新令牌是否还有效。刷新接口返回未登录，才回到登录页。
- 不把登录失败拆成「账号不存在」和「密码错误」。
- 不在资料接口修改用户名、手机号、邮箱、密码、状态或角色。
- 不提交 `provider_user_id`。第三方用户标识只由服务端用授权码换取。
- 不把发送验证码的成功展示成短信或邮件已经送达。这个接口只生成验证码，当前不会真正发送。
- 不在本模块做商品、社区、订单，也不读取其他用户的资料、设备或身份。
