# AI 定制服装商城 — 总开发清单
你平时做到哪勾到哪 只管前端的 内容不一定对 不对的地方你就改 
## 一、项目技术栈

### 前端
- React
- TypeScript
- Vite
- Ant Design
- Tailwind CSS
- Zustand
- TanStack Query
- HTML Canvas 2D

### 后端
- Go
- Gin
- GORM
- PostgreSQL
- Redis
- JWT
- Casbin RBAC
- WebSocket
- 对象存储

### 项目原则
- 前后端分离
- RESTful API
- 统一 JSON 响应格式
- 统一错误处理
- 用户身份认证及权限控制
- 设计数据持久化

**禁止引入 Three.js、GLB、GLTF、Blender、UV 映射及任何 3D 模型相关技术。**

# 十二、开发顺序

严格按照以下顺序推进：

1. 用户与认证（前端已完成，头像还不能选文件上传）
2. 服装模型与基础配置（设计器已接款式和颜色接口，没有面料）
3. 设计器与设计版本（设计器可用。款式、颜色和图库已接接口，设计保存还在这台浏览器里）
4. AI 生图
5. 社区
6. 商城
7. 订单与支付
8. 聊天
9. 后台管理

全局公共能力根据各模块实际需要同步建设，不必等到最后才开发。
