# INKTEE

前端脚手架。路由、布局、Ant Design、TanStack Query 和请求封装已经接好，业务页面还没有接上。

## 命令

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

开发服务器默认地址是 `http://localhost:5173`。

## 环境变量

见 `.env.example` / `.env.development`：

| 变量 | 说明 |
|------|------|
| `VITE_API_BASE_URL` | API 基础地址，开发默认 `http://localhost:8080/api` |
