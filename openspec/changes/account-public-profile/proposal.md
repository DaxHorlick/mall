# Proposal

## Why

账号页现在按认证表单展示手机、邮箱、状态、角色和设备。Dezajn 的公开主页展示的是名字、用户名、头像、横幅、简介、社交链接、粉丝数和作品。账号页的显示和数据范围要对齐这一块。

## What Changes

- 已登录的账号页顶部改为公开主页：名字、用户名、头像、横幅、简介、社交链接、粉丝数、作品。
- 名字用 `nickname`，用户名用 `username`，头像用 `avatar_url`，加入时间用 `created_at`。这些字段来自当前用户。
- 横幅、简介、社交链接、粉丝数和作品没有对应接口，只显示空状态。不造数据，不请求新接口，不新增可编辑字段。
- 不放关注、分享、店内搜索和作品筛选。这些操作没有对应数据。
- 资料、密码、登录设备、第三方身份和退出仍留在主页下面，请求、校验和完成后的去向不变。`docs/用户与认证.md` 要求这些操作在账号页完成。
- 手机、邮箱、状态、角色和用户 ID 不再放进主页头部，仍可在下面的资料区看到。
- 登录、注册、404、路由和顶栏页脚不改。不使用 Dezajn 的照片、标志或英文文案。

## Capabilities

### New Capabilities

- `account-profile`: 已登录账号页按公开主页的数据范围展示，缺数据时为空状态，原有账号操作仍留在同一页。

### Modified Capabilities

- 无。`openspec/specs/` 里还没有已归档的能力。

## Impact

- 只改 `src/pages/account/index.tsx` 的展示。不改接口、环境变量、路由、登录、注册和 404。
- 不新增字体、图片或依赖。
- 未归档的 `restyle-auth-pages` 要求账号页仍以原顺序的表单开头。这次用公开主页头部取代这个开头；下面的资料、密码、设备、第三方身份和退出保持原顺序。
