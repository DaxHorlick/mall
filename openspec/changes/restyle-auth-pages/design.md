# Design

## Context

外观分散在 `src/index.css` 的页面底色、`src/App.tsx` 的 Ant Design 主题，以及 `MainLayout` 和四个页面上的 Tailwind 类。主按钮已经是 `Button type="primary"`，输入框圆角来自主题的 `borderRadius: 10`。项目约定不把只用一次的包装拆出去，也不新增字体或图片文件。需求见 `specs/shell-appearance/spec.md`。

## Goals / Non-Goals

**Goals:**

- 用现有的 Ant Design 主题和 Tailwind 类换掉底色、标题、顶栏和主按钮。
- 登录和注册的标题放在圆角色块上，色块只用纯色或渐变。
- 输入框继续用主题圆角，不跟主按钮一起变成胶囊。

**Non-Goals:**

- 不新增组件文件、字体文件或图片。
- 不改表单字段、校验、请求和路由。
- 不把账号页改成海报式首屏。

## Decisions

### 颜色和字体留在现有主题里

`index.css` 的 `body` 和 `MainLayout` 根节点改为白底、`#17181b` 文字。`ConfigProvider` 的 `colorPrimary` 改为 `#17181b`，`borderRadius` 保持 10，字体栈继续是 Segoe UI、苹方、微软雅黑。

不引入 Geist 或手写标志。中文本来就会落到苹方或微软雅黑，再加一套拉丁字体文件没有必要。

备选是单独写一套按钮样式、绕开 Ant Design。那样登录和账号的按钮会对不齐，所以不用。

### 主按钮用 `shape="round"`，输入框不改

登录、注册、保存资料、修改密码、404 的主要按钮，以及顶栏已登录时的「退出」，使用 `type="primary"` 和 `shape="round"`。Ant Design 的 round 按高度取圆角，所以即使主题圆角是 10，按钮仍是胶囊。

次要按钮和危险按钮不加大 `type="primary"`，因此不会变成同一颗黑胶囊。输入框、选择框继续吃主题的圆角 10。

备选是给所有控件把 `borderRadius` 设成 999。账号页的长表单会变成一排胶囊，规格明确不要这样。

### 登录和注册用色块，不用照片

登录和注册的标题区是一个圆角块，背景用近黑到深暖色的渐变，标题和说明改成白色。表单留在白底上，窄屏时色块在上、表单在下。色块里不放图片。

账号和 404 的标题留在白底上，字号用 `text-4xl`、字重 400。登录和注册的标题用 `text-5xl`、字重 400、行高收紧。账号页很长，不跟登录页抢同一级海报标题。

### 顶栏改为实心白，标志不再拉字距

顶栏去掉半透明和模糊，保持吸顶。标志改为正常字距的中等字重文字。页脚第二行由「前端脚手架」改为「原创服饰」。版权行不动。

### 类名写在现有页面里

四个页面重复同一组标题类，不抽公共标题组件。改动只发生在已有文件的 `className`、主题 token 和页脚那一句。

## Risks / Trade-offs

- [顶栏「退出」变成主按钮后比现在显眼] → 规格要求已登录时右侧是黑色胶囊，接受这个对比。
- [Ant Design 的 round 在小尺寸上仍可能看起来偏方] → 主按钮保持 `size="large"`；顶栏退出用默认尺寸并在浏览器里看一眼高度。
- [渐变色块在注册页把说明文案压成白字，长文案占高] → 色块只包标题和一句说明，表单和错误提示仍在白底上。
- [页脚「原创服饰」比当前功能范围更大] → 它只替换脚手架自述，不增加商品页面。

## Migration Plan

改样式后重新跑 `npm run dev` 看登录、注册、账号和 404。没有数据迁移。回退就是还原这几个文件的样式改动。

## Open Questions

无。页脚短句定为「原创服饰」。
